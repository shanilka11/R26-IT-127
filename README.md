# AI-Based Spatio-Temporal Demand Forecasting and Adaptive Seat Allocation

This workspace contains a prototype end-to-end system for demand forecasting and seat allocation using ML models, FastAPI backend, and a React frontend.

Structure:
- /backend: FastAPI backend, models, utils
- /frontend: React (Vite) prototype UI
- sri_lanka_railway_dataset.csv: dataset (must exist at workspace root)

See RUN_INSTRUCTIONS.md for setup and run steps.
